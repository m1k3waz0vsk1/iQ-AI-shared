# iQ-AI-shared

Спільне сховище скілів і скриптів для КД IQ Composite.

- `release/` — чинні версії. Змінює лише власник скілу (kd-*: Андрій). Кожна зміна записується в `release/CHANGELOG.md`.
- `proposals/<ім'я>_<що>/` — пропозиції змін до чужих скілів: змінений файл + `ОПИС.md` (що, навіщо, на якому виробі перевірено). Власник переглядає і переносить у `release/`.
- `<ім'я>/` — особиста зона: чернетки, власні скіли. Готовий скіл переходить у `release/` і отримує власника.

Не редагуйте файли в `release/` напряму, навіть якщо Drive це дозволяє.

# kd-dxf-pack

Підготовка завдань на розкрій: заявка → DXF з КД → нестинг (Sparrow) → DXF листів. CNC поки не входить.

## Структура
- `tools/` інструменти (лише стандартний Python 3, без бібліотек)
  - `find_product.py` зіставлення заявки з папками КД, статуси OK / ПЕРЕВІРИТИ / ЗАБЛОКОВАНО
  - `strip_holes.py` БО з DXF з отворами: лишає лише зовнішній контур (правило 27.10.2026, позиції з `derive_bo` у match.json)
  - `nest_tools.py` перетворення jobs.json + DXF у вхід Sparrow (`prep`) і збирання листів з результату (`layout`)
  - `nest_run.py` повний нестинг завдання (кілька листів, залишки); `verify_sheets.py` незалежна перевірка листів
  - `run_nesting.sh` ручний запуск нестингу без служби
  - `build_sparrow.sh` одноразова збірка Sparrow у `~/sparrow` (потрібні Xcode CLT, Rust 1.90+)
  - `dxf_contours.py` діагностика DXF: контури, вкладеність, отвори
- `zavdannia/<дата>/` одне завдання
  - `dxf/` DXF виробів, точні копії з КД
  - `preview/` превʼю контурів
  - `ІНСТРУКЦІЯ_нестинг_і_CNC.md`, `jobs.json` результат скіла kd-dxf-pack
  - `nesting/` вхід Sparrow, `output/` його відповідь, `layout_<група>/` листи DXF/SVG і звіт
- `aliases.json` підтверджені зіставлення «назва із заявки → папка КД»
- `profiles.json` параметри нестингу; `queue/` черга служби; `service/` служба launchd (install.sh / uninstall.sh)
- `skill/SKILL.md`, `skill/kd-nesting.SKILL.md` копія тексту скіла для довідки (діючий скіл зберігається в Claude)

## Запуск нестингу
Через службу (так робить Claude): файл-запит у `queue/`, результат у `zavdannia/<папка>/nesting/`.
Вручну: `./tools/run_nesting.sh zavdannia/2026-10-22 [секунд_на_спробу]`.
Параметри (підтверджено): відступ 7 мм, поле 10 мм, будь-який кут, фреза 6 мм. Змінюються в `profiles.json`.

## Правила
- КД лише для читання. DXF беруться з підключеної папки КД (Google Drive for desktop), не через чат.
- Різні матеріали в один нестинг не змішуються (групи в jobs.json).
- Отвори, виборки, Ø30 у нестингу не беруть участі, але є в DXF листа (шар PARTS). Лист на шарі SHEET, підписи на LABELS.

## CNC (скіл kd-cnc)
- `tools/gen_cnc.py <папка завдання> лист_A_N | --all [--out ПАПКА]`: G-код у форматі еталона ArtCAM з `nesting/лист_A_N.dxf`, перевірка файлу вбудована.
- `tools/cnc_rules.json`: правила (глибини, подачі, діаметри виточок). Змінює лише користувач.
- Нестинг більше не пише написи в DXF (номери лишаються лише в SVG).
